# AgentForge 视频功能路线图

> 更新时间：2026-08-31　适用范围：视频功能 M 系列迭代线
> 背景：AgentForge 主流程（P1–P5）已全部完成；视频是主线之后的开放式增量线。视频 M 系列里程碑在源码中以 `M{n}` 注释 + 里程碑迭代推进，不设固定总数，仅维护「已完成基线」与「未来候选梯队」。

## 1. 已完成基线（能力现状）

以下为已落地、可复用的视频能力（按能力域归纳，非严格编号）：

| 能力域      | 关键实现                              | 对应里程碑 |
| -------- | --------------------------------- | ----- |
| 单视频生成闭环  | 提交 → 轮询 → 下载落盘，事件实时推送进度           | M1–M3 |
| 视频消息与任务卡 | 聊天内视频渲染、任务进度卡、Pinia store         | M3    |
| 多厂商支持    | Seedance / 可灵（Kling）双厂商 + 设置页     | M4    |
| 多镜头序列    | 一次性并行提交、统一轮询、镜头序号管理               | M6    |
| 序列 UI    | 序列卡片（SequenceCard）展示              | M7    |
| 连续性衔接序列  | 镜头 i 尾帧自动作为镜头 i+1 首帧（ffmpeg 尾帧抽取） | M8    |
| 视频资源管理面板 | 集中管理任务与序列、单条重试/取消/删除              | M9    |

## 3. 规模估算与推进建议

* **中期梯队（M14–M16）**：约 3 个里程碑，可结合使用反馈挑选。
* **远期梯队（M17–M20）**：开放候选，无排期承诺，随需求变化增删。

推进方式：沿用既有迭代模式——先出「里程碑方案」文档（含范围/变更清单/验收标准），确认后实施并以 `typecheck / lint / test / build` 全绿为完成门槛。
