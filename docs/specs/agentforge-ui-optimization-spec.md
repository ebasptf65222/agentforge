# AgentForge UI 优化规格 v0.3

## 背景

当前应用已完成核心功能（聊天、知识库、设置、语音、工作区），但在用户体验层面存在多个可提升点。本次优化聚焦交互细节、视觉引导和功能完整性，共 13 项。

---

## 需求清单

### OPT-UI-01 聊天视图空状态引导

**现状**：新建对话后聊天区域为空白，无引导。
**目标**：添加欢迎空状态页，展示快捷入口、快捷键提示、示例 Prompt。
**设计**：
- 居中展示 AgentForge Logo + "开始一段新对话"标题
- 三列快捷入口卡片：新建对话、配置模型、导入知识库
- 底部快捷键提示栏：Ctrl/Cmd+B 切换侧边栏、Shift+Enter 换行
- 示例 Prompt 区域：3-4 个可点击的预设问题

### OPT-UI-02 消息气泡操作按钮

**现状**：消息展示后无法复制、重试、编辑或删除。
**目标**：hover 时显示操作工具栏。
**操作项**：
- 复制：一键复制消息全文到剪贴板
- 重试（仅助手消息）：重新生成该条回复
- 编辑（仅用户消息）：编辑消息内容并重新发送
- 删除：删除单条消息（需确认）

### OPT-UI-03 Skill 选择器可发现性

**现状**：NSelect 默认显示"普通对话"，用户不清楚 Skill 是什么。
**目标**：增强 Skill 的可发现性和状态感知。
**设计**：
- 选中 Skill 后，输入框上方显示轻量提示条："当前模式：[Skill 名称] — [描述]"，带关闭按钮回到普通对话
- Skill 选项的 tooltip 显示触发方式和说明

### OPT-UI-04 会话列表删除确认

**现状**：点击删除直接删除会话，无二次确认。
**目标**：增加删除确认弹窗。
**设计**：使用 naive-ui NPopconfirm，文案："确定删除会话「xxx」吗？此操作不可撤销。"

### OPT-UI-05 知识库导入弹窗简化

**现状**：分块策略、大小、重叠量等参数对非技术用户不友好。
**目标**：隐藏高级参数，默认使用智能推荐。
**设计**：
- 默认折叠高级参数，显示"智能分块（推荐）"标签
- 添加"高级设置"折叠面板，展开后显示 chunkSize / overlap
- 参数旁添加 tooltip 说明

### OPT-UI-06 知识库批量操作

**现状**：文档操作只能逐个进行。
**目标**：支持多选 + 批量操作。
**设计**：
- NDataTable 添加 selection 列
- 选中后显示批量操作工具栏（批量删除、批量索引）
- 支持全选/取消全选

### OPT-UI-07 设置搜索/快速跳转

**现状**：六个 Tab 需逐个切换浏览。
**目标**：支持按关键词搜索设置项。
**设计**：
- SettingsView 顶部添加搜索框
- 输入关键词时实时过滤匹配项，高亮对应 Tab
- 点击结果直接跳转到对应 Tab 并滚动到目标位置

### OPT-UI-08 语音面板语速标签和档位

**现状**：语速 slider 无当前倍速显示。
**目标**：添加直观标签和快捷档位。
**设计**：
- slider 旁显示当前倍速（如 "1.0x"）
- 添加 0.75x / 1.0x / 1.25x / 1.5x 快捷按钮

### OPT-UI-09 文件面板扩展功能

**现状**：仅支持浏览和预览。
**目标**：增加右键菜单和快捷引用。
**设计**：
- 右键菜单：复制路径、在文件管理器中打开
- 文件预览支持代码高亮（基于文件扩展名判断语言）
- 支持将文件路径快速插入聊天输入框（点击按钮或拖拽）

### OPT-UI-10 ThinkingBlock 可复制

**现状**：思考过程展示后无法复制。
**目标**：添加复制按钮。
**设计**：在 ThinkingBlock 展开内容区域的右上角添加"复制"按钮。

### OPT-UI-11 审批卡片预览增强

**现状**：仅显示 JSON 参数。
**目标**：对常见工具增加可视化预览。
**设计**：
- 文件写入：diff 预览（前后对比）
- shell 命令：命令高亮 + 安全提示
- 其他工具：保持 JSON，但添加格式化折叠

### OPT-UI-12 键盘快捷键体系完善

**现状**：仅支持 Ctrl/Cmd+B。
**目标**：补充常用快捷键。

| 快捷键 | 功能 |
|--------|------|
| Ctrl/Cmd+N | 新建对话 |
| Ctrl/Cmd+K | 聚焦到对话搜索/切换 |
| Ctrl/Cmd+Shift+K | 打开知识库 |
| Ctrl/Cmd+, | 打开设置 |
| Ctrl/Cmd+Enter | 发送消息 |
| Escape | 停止生成 |

### OPT-UI-13 主题切换实时预览

**现状**：下拉选择主题，切换后才能看到效果。
**目标**：使用可视化的主题选择器。
**设计**：NRadioGroup + 主题色块预览卡片（深色/浅色/跟随系统），选择后立即生效。

---

## 技术约束

- 使用 naive-ui 组件优先，保持视觉一致性
- 保持现有 Pinia store 架构
- 所有新增操作需有错误处理和 toast 反馈
- 响应式布局，适配不同窗口尺寸
